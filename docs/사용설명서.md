# 아파트온 사용 설명서 (관리사무소용)

## 처음 한 번만 하는 준비

1. **아파트 등록** — 처음 접속하면 `시작하기`를 눌러 아파트 이름, 관리사무소 전화번호, 관리자 이메일·비밀번호를 입력합니다.
2. **동·호수 만들기** — 메뉴 `동·호수` → 동 이름(예: 101동), 시작 층, 꼭대기 층, 층당 세대 수를 넣고 `동 추가`. 구조가 불규칙하면 `직접 입력`에 `101, 102, 201~204`처럼 적습니다.
3. **입주민 연락처 등록** — 메뉴 `입주민 연락처`
   - 한 명씩: `＋ 연락처 한 명씩 등록` → 동·호수, 휴대전화, 수신 동의 상태
   - 여러 명: `엑셀·CSV로 한 번에 등록` → 양식 내려받기 → 채워서 올리기. 잘못된 줄은 이유와 함께 알려 줍니다.
   - **수신 동의가 확인된 번호에만 문자가 갑니다.** 동의서를 받기 전이라면 `동의 확인 전`으로 두세요.
   - 한 세대에 여러 번호 가능, 같은 번호가 여러 세대에 있어도 한 공지는 1번만 갑니다.

## 공지 보내기 (가장 많이 쓰는 기능)

홈의 큰 파란 버튼 **＋ 새 공지 작성**을 누릅니다. 한 화면에서 위에서 아래로 채우면 됩니다.

1. **어떤 공지인가요?** — 엘리베이터 점검, 물탱크 청소 등을 누르면 제목과 안내 문구가 자동으로 채워집니다.
2. **제목과 안내 내용** — 필요한 만큼 고칩니다.
3. **일정** — 시작·종료 날짜와 시간(긴급 공지는 비워도 됨).
4. **누구에게** — 전체 세대 / 동 선택(여러 동 가능) / 호수 선택.
5. **보낼 문자 확인** — 위 내용으로 문자가 자동 작성됩니다. 직접 고칠 수도 있습니다. 오른쪽(휴대폰은 아래)에 받는 사람 화면, 받는 사람 수, 예상 비용이 나옵니다.
6. **언제** — 지금 바로 / 예약. 일정이 있으면 3일 전·1일 전 오전 9시, 당일 오전 8시 재안내도 고를 수 있습니다.

`발송 내용 확인`을 누르면 **최종 확인 창**(문자 내용·대상·받는 사람 수·문자 종류·예상 비용)이 뜹니다. `발송하기`(또는 `예약하기`)를 눌러야 실제로 진행됩니다. 실제 발송 모드에서는 확인 체크를 해야 버튼이 눌립니다.

> 💡 간단히 적으면 AI가 공지문으로 다듬어 주는 기능은 서버에 AI 키가 설정된 경우에만 보입니다. AI는 메모에 없는 날짜·사유를 만들지 않도록 지시되어 있고, 메모에 없던 숫자가 들어가면 경고합니다. 반드시 확인 후 사용하세요.

### 긴급 공지
홈의 빨간 **🚨 긴급 공지 발송** → 머리말이 `[아파트명 긴급안내]`로 바뀌고 바로 발송됩니다.

## 보낸 뒤 확인하기

공지를 보내면 상세 화면으로 이동합니다.
- **성공 확인 / 처리 중 / 실패 / 확인 불가** 수와 수신자별 결과(번호는 뒷자리만)
- 통신사 결과는 보통 몇 초~몇 분 안에 들어오며 화면이 자동으로 새로 고쳐집니다.
- **실패 N건 재발송**: 실패한 번호에만 다시 보냅니다.
- **결과 확인 불가**: 문자가 실제로 갔는지 알 수 없는 경우입니다(통신 오류 등). 중복 문자를 막기 위해 자동으로 다시 보내지 않습니다. SOLAPI 콘솔에서 확인한 뒤 필요할 때만 재발송하세요.
- **예약 취소/수정**: 예약된 회차는 발송 시작 전까지 취소·수정할 수 있습니다. 이미 문자 서비스로 넘어간 건은 취소할 수 없습니다.
- **이 공지 다시 보내기**: 이전 공지를 불러와 고친 뒤 다시 보냅니다.

`공지 내역`에서 제목·내용·대상으로 검색할 수 있습니다.

## 입주민이 보는 화면

- 문자를 받습니다(별도 앱 없음).
- `공지 확인 링크 넣기`를 켜면 문자 끝에 링크가 붙어, 공지 상세와 이전 공지·다가오는 일정을 볼 수 있습니다.
- `세대별 안내`로 보낸 공지는 공개 페이지에 올라가지 않고, 받은 사람마다 다른 개인 링크로만 열립니다(90일).

## 테스트 모드 ↔ 실제 발송

- 화면 맨 위 **노란 띠 = 테스트 모드**: 실제 문자가 나가지 않고 요금 0원. 끝자리가 `0000`인 번호는 일부러 '발송 실패'로 처리해 실패 화면을 확인할 수 있습니다.
- **초록 띠 = 실제 발송**: 입주민에게 문자가 가고 요금이 발생합니다.
- 전환: `설정` → 발송 방식 `실제 발송` + 발신번호 입력 → 저장 (서버에 SOLAPI 키가 있어야 선택 가능). `연결·잔액 확인(무료)`과 `내 휴대전화로 1건 보내기`로 먼저 확인하세요.

## 비용

`문자 비용` 메뉴에서 이번 달 건수, 추정 비용(VAT 별도/포함), 단문·장문 비율, 공지별 비용, SOLAPI 잔액을 봅니다. 단가는 `설정 → 문자 요금`에서 SOLAPI 계약 단가로 바꿀 수 있습니다. 실패 건은 비용에서 뺍니다. 정확한 청구액은 SOLAPI 콘솔이 기준입니다.

## 개인정보 지키기

- 번호 전체 보기(`보기`), 수정, 삭제, 발송은 모두 `설정 → 변경·발송 이력`에 남습니다.
- 전출 세대는 `전출 처리`로 발송을 막고, 필요 없어지면 삭제하세요.
- 광고·홍보 문자는 보내지 마세요(별도 동의·(광고) 표기 등 법적 의무). 작성 중 광고성 표현이 보이면 경고합니다.
- 직원 계정은 `설정 → 직원 계정 추가`로 만들고, 퇴사 시 `비활성화`하세요.
